# Slide Fourteen / 第十四號載玻片

A trilingual browser mystery for a human observer and an AI analyst.

Languages: Simplified Chinese, Traditional Chinese (Taiwan), and English.

## Play

- Language entry: https://slidefourteen.org/
- Traditional Chinese — 第十四號載玻片: https://slidefourteen.org/zh-hant/
- Simplified Chinese — 第十四号载玻片: https://slidefourteen.org/zh-hans/
- English — Slide Fourteen: https://slidefourteen.org/en/

## Access from Mainland China

GitHub Pages may be directly reachable from Mainland China, but GitHub does not
guarantee stable availability there. If the game does not load, retry later or
use another network.

The public repository contains only the compiled web game. The editable source
archive is preserved separately.
